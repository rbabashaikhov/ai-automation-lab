## 7. Known limitations

- **Phase 4F.2 stands.** `4F.2 HOLD — PRODUCT ACCEPTANCE FAILED` is not changed by this phase. The 4F.1 release gate (15 scenarios, its thresholds) was not re-run and is not met; the product is not accepted as production-ready. The other 4F.2 findings (qualitative language, bright-room and best-for-movies reasoning, ranking, MINOR issues) were out of scope and are untouched.
- **Invented numeric limits are still voiced (the reason for the hold).** Since 4E.2 the guard removes a number the user never stated before it reaches the Core, and 4F.3 extended it to slang and spelled numbers. That part is deterministic. The answer text is not checked: in the «подешевле» conversation the model words its removed ceiling as a fact in 12/12 sessions («до 50 000 ₽»), and after «не огромный» it words «до 55 дюймов» in 15/20. A result-side note for removed numeric limits was tried and changed nothing (14/20), so it was not adopted.
- **Rates, not guarantees.** gpt-4.1-mini at temperature 0 does not repeat itself. The HDMI 2.1 claim went from 20/20 to 0/20 and 0/10 on the two recorded questions, the false «все на 60 Гц» from 3/10 to 0/20, the Dolby Atmos count is exact in 10/10. A zero rate in 20 sessions is not a proof of zero.
- **No answer-level check.** Feature evidence is deterministic for a feature that was asked about (named by the user, or required by the model and removed by the guard): the result then says yes / no / not listed per product. A claim about a feature nobody asked about, or wording beyond the evidence, is still only governed by the prompt.
- **Three tool calls per turn.** A question about four models makes the model issue four parallel lookups; the fourth is refused by design and the answer covers that model from memory or drops it (DEMO-02).
- **«Подешевле» without a search.** When the model answers from the previous result instead of searching in price order, the options respect the stated limits but are not necessarily the cheapest ones (PA-08 turn 3).
- **Wording.** Lists are sometimes longer than three (5 in PA-02; all 8 shown products in 3/20 sessions), a feature id appeared once («hz_120»), and «не у всех» is used where the exact statement is «listed for N, no data for M».
- **Counts cover registry features and structured columns only.** `get_catalog_stats` counts the 14 Feature Registry features (yes / no / not listed) and groups by structured columns; listed values are given for features that carry a value, as a range above 12 distinct values. An attribute outside the registry has no count.
- **Evaluation path.** As in 4F.2, conversations run through a temporary inactive n8n driver with the committed workflow inline; the Consultant workflow itself stays inactive and has no public trigger.

## 8. Safety

- No ingestion, no indexing run, no embedding generated or regenerated. The only model calls are the Consultant turns of the runs and measurements, through the existing n8n credential and the accepted model.
- No product-data mutation: the Consultant's read-only role and read-only transactions only; the catalog fingerprint (products, prices, availability, spec rows, chunks, embeddings) is identical before the first deploy and after the last run.
- No credential exposure: no API key, password or token was read, printed, exported or stored. The MCP token was piped on the VPS between two processes; the n8n API key was used only inside the existing tooling; every generated file is scanned for key patterns before it is written.
- No unrelated n8n change: the 15 other workflows are unchanged (id, name, active, updatedAt). The Consultant workflow was updated with `n8n-tool` (a backup before each update) and stays inactive. One temporary inactive driver was created and deleted.
- No unrelated infrastructure change: only the `samsung-consultant` service was redeployed (image tag in its compose file). n8n, PostgreSQL, Redis and Traefik were not restarted; no database role, schema, network, port or proxy rule was changed. finance_tracker was not touched.
- The OpenAI credential was not touched. n8n reports a new display name for the same credential id (`OpenAI account samsung-ai`); the workflow generator's label was aligned with it so that the read-back comparison is clean.
- The model was not changed and its cost was not raised: gpt-4.1-mini, temperature 0; no bake-off.
