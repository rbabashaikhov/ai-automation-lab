## 8. Safety

- No database or catalog mutation: read-only role and read-only transactions only; the catalog fingerprint is identical before and after.
- No ingestion, no indexing, no embedding generated. The only model calls are the 90 Consultant turns themselves (53 + 37), through the existing n8n credential.
- No secret was read, printed or stored: the MCP token was piped on the VPS; the n8n API key was used only inside the existing tooling; every generated file is scanned for key patterns before it is written.
